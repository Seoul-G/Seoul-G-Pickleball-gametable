🥎 피클볼 아메리카노 대진표 v1.0.3 Compat 동기 로드 · 즉시 진단

로테이션(파트너 자동 교체) · 고정 파트너 모드 · 코트 자유 설정 · 중간 합류/이탈 · 점수 기록 & 링크 공유

제작자: 김건희
📌 진행 방식 — 각 경기에서 두 팀의 스코어를 입력하면 승리 팀이 자동 판정됩니다(승리 +2점, 패배 +1점). 로테이션 모드는 라운드마다 파트너가 자동 교체되고, 고정 파트너 모드는 같은 파트너끼리 계속 경기합니다. 인원 변경 시 "기회 대비 출전"이 균등해지도록 재생성되며, 공유 링크로 대진표·점수를 주고받아 동기화할 수 있습니다.

⚙️ 대회 설정

코트는 직접 입력 가능하며, 실제 사용은 라운드별 활성 인원 ÷ 4까지만 자동 적용됩니다. 고정 파트너 모드에서는 참가 인원이 짝수여야 합니다(홀수면 마지막 1명은 출전 불가).

✏️ 대진표 수정 특정 라운드부터 합류 / 이탈

변경 적용 시 해당 라운드 이전 대진·기록은 🔒 유지되고 이후 라운드만 재생성됩니다. "기회 대비 출전"이 모든 선수(또는 팀)에게 균등해지도록 자동 배분됩니다.

📤 공유 & 점수 동기화 링크 전달 방식

사용 방법: ① "공유 링크 복사"로 링크/코드를 메신저로 전송 → ② 받는 사람이 링크를 열거나 "링크·코드에서 불러오기"에 붙여넣으면 대진표·점수 표시 → ③ 점수를 입력한 뒤 다시 링크를 보내주면 동기화됩니다. (별도 서버 없이 상태를 링크에 담는 방식이라 실시간 자동 동기화는 아닙니다.)

🔴 실시간 동기화 Firebase 미설정

같은 방 코드로 연결된 기기끼리는, 한쪽에서 점수·대진표를 수정하면 다른 쪽 화면에 즉시 반영됩니다. 아래에 Firebase 콘솔에서 복사한 웹 설정(config)을 붙여넣고 새로 업로드하면 즉시 작동합니다.

🩺 동기화 진단 대기

❗ 점수 강제 동기화는 현재 대진표를 Firebase에 다시 올립니다. 다른 기기에서 보이지 않으면 진단 카드의 '최근 이벤트'에 오류 코드(PERMISSION_DENIED, ERR_NAME_NOT_RESOLVED 등)가 그대로 표시되니 그 한 줄만 알려주세요.

📋 대진표

각 경기의 두 팀 점수칸에 스코어를 입력하면 승리 팀이 자동 결정됩니다(예: 11 – 8). 점수를 지우면 기록이 취소되고, 동점 입력은 인정되지 않습니다.

🏆 순위표 승리 +2 / 패배 +1

출전/기회 = 실제로 뛴 라운드 수 ÷ 참가 가능했던 라운드 수(합류 시점·이탈 시점 자동 반영). 동점자는 승리 수 → 득실 → 이름 순으로 정렬됩니다.

코트 설정 — 사용 코트 수를 직접 입력할 수 있습니다(라운드별 인원÷4 이하로 자동 제한).
모드 — 로테이션: 라운드마다 파트너·상대가 자동 교체 / 고정 파트너: 파트너는 그대로, 팀 대 팀 대진만 로테이션. 모드를 바꾸면 대진과 기록은 초기화됩니다.
운동 횟수 균등 — 매 라운드 "기회 대비 출전 비율이 낮은 선수(팀)"부터 우선 투입해 모든 참가자가 공평하게 운동합니다.
대진 알고리즘 — 파트너·상대 중복을 최소화하는 조합을 60회 탐색해 최적안을 채택합니다. 8명(2코트) 로테이션이면 전원이 서로 정확히 한 번씩 파트너가 되는 완전 대진이 생성됩니다.
동기화 한계 — 실시간 동기화가 아닌 링크 전달 방식입니다. 인터넷에 올려두면(예: Netlify Drop) 휴대폰에서도 링크만으로 쉽게 열 수 있습니다. v1.0.3 · Compat 동기 로드 · 즉시 진단 패널 · 제작자: 김건희
